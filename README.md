# Java - Recursividade

## 📖 Objetivo

Este repositório reúne exercícios acadêmicos desenvolvidos em Java com foco na utilização de funções recursivas para resolução de problemas computacionais.

## 📂 Conteúdo

O repositório contém exercícios sobre:

- Funções recursivas;
- Chamadas recursivas;
- Condições de parada;
- Desenvolvimento da lógica de programação;
- Entrada e saída de dados.

## 💻 Tecnologias

- Java
- Eclipse IDE

## ▶️ Como executar

1. Instale o Java JDK em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Abra o projeto no Eclipse IDE.
4. Execute a classe Java desejada.
